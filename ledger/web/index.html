      A SMALL, EXPLAINABLE HARNESS
      
        
      Built to show its work.
      
        
      
          Inspired by TradingAgents, Kronos, SimpleMem, and ReHarness.
        
      
        
      
          Source snapshot → 4 analysts →
          Bull / bear → Manager + risk →
          Thesis memory
        
      
        
      
          
      
            
      Disagreement is useful data.
      
            
      
              Analysts form their views before seeing the quantitative forecast.
              The manager then compares the debate with forecast scenarios. A
              risk reviewer can force abstention; the interface preserves
              dissent rather than averaging it into artificial confidence.
            
      
            
      Bounded work, explicit state.
      
            
      
              One or two debate rounds. At most 16 model attempts across
              resumes. A four-minute orchestration deadline. Validated report
              schemas and citation IDs. Completed stages are persisted in
              SQLite.
            
      
          
      
          
      
            
      Remember less. Preserve provenance.
      
            
      
              Store the thesis, invalidation condition, regime, date, and source
              IDs—not full conversations in every prompt. Retrieve by asset,
              mode, date, and lexical relevance. Demo memory never enters live
              research.
            
      
            
      Revise without rewriting history.
      
            
      
              Feedback can narrow a memory to its original snapshot or retire
              it. The source claim remains immutable. This is a conservative
              adaptation of recurrent memory, not a reproduction of ReHarness or
              SimpleMem's full algorithms.
            
      
          
      
        
      
        
      
          
      What this version does—and what remains to test
      
          
      
            Demo reports are deterministic fixtures. Live mode uses your
            configured model and Alpha Vantage credentials. Real Kronos
            inference requires its upstream package and model weights. Bootstrap
            scenarios are clearly labeled and evaluated against a no-change
            baseline. Neither forecast establishes profitability.
          
      
          
      
            This is an orchestrated multi-agent workflow, not an autonomous
            trading agent. There is no broker integration, no trained
            reinforcement learning policy, and no claim to reproduce the papers'
            benchmark results. Semantic retrieval, automatic outcome settlement,
            and multi-user authentication are future extensions.
